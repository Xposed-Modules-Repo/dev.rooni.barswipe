# Changelog

## 1.0.3 (2026-10-27)
- Новая адаптивная векторная иконка Material You с динамическими цветами Monet и Themed Icons (Android 13–16).
- Плавная физическая анимация скрытия/раскрытия статус-бара.
- Тактильный виброотклик на жесты свайпа.
- Защищенный режим выполнения хуков (Protective Mode) на базе LibXposed API 101.
- Ультралегкий размер релизного APK (~17 КБ).
